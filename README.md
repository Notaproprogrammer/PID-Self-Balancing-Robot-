# PID-Self-Balancing-Robot-
Hello, I made a Self Balancing Robot using PID this summer. 
I used the following Hardware compononents: 
1. Raspberry Pi Pico 2
2. MPU 9265
3. Motor Driver l298n
4. 2 Yellow Gear Motors
5. 2 * 3.7V battery + switch
wiring:
From motor driver: ENA - GP21, ENB- GP20, IN1- GP6, IN2-GP7, IN3-GP8, IN4-GP9
From MPU-9265: 
SCL-GP5, SDA-GP4
VCC - 3v3 (3.3 V)  
GND - GND
